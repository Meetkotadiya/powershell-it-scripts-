# powershell-it-scripts-
This repository contains 5 PowerShell scripts designed for Windows system administration, monitoring, troubleshooting, and reporting tasks.

---

## Scripts Overview

### 1. Disk Space Report
Checks disk usage, free space, and usage percentage for all drives.

### 2. Installed Software Report
Lists installed applications and exports results to a CSV file.

### 3. Service Status Checker
Checks important Windows services and attempts to restart stopped services.

### 4. System Information Report
Displays system details such as OS version, CPU, RAM, uptime, and user info.

### 5. Network Connectivity Test
Tests connectivity to multiple websites and shows response times.
